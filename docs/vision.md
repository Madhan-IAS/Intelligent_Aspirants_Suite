# UPSC KMS - Vision Document

## Purpose
The UPSC Knowledge Management System (KMS) is a personalized digital brain and operating system designed for UPSC CSE preparation. It centralizes notes, links current affairs with static subjects, tracks the 3-5-7 revision schedule, manages PYQs (Previous Year Questions), and monitors overall progress. 

## Primary Users
The platform is designed as a single-user system tailored for the developer (Madhan), acting as a "source of truth" throughout the 18–24 month preparation journey for the 2027 attempt.

## Key Problems Solved
- Disorganized notes scattered across multiple apps (Notion, Evernote, Obsidian) and Telegram channels.
- Difficulty in tracing the connection between daily current affairs and static syllabus subjects.
- Lack of automated scheduling and tracking for the 3-5-7 spaced repetition method.
- Poor searchability of themes and topics across General Studies (GS) and Optional subjects.

## Main Features (Version 1)
- **Dashboard**: Today's tasks, study hours, pending revisions, current streak.
- **GS Modules (I-IV)**: Organized repository of static subjects.
- **Sociology Optional**: Syllabus-wise breakdown of Paper I and Paper II.
- **Current Affairs Integration**: Linking daily articles to static subjects.
- **3-5-7 Revision Engine**: Automated scheduling (1, 3, 7, 15, 30, 90 days).
- **Search System**: Global search returning results across all modules.

## Features Deferred to Version 2
- AI integration (Ask questions, generate summaries, flashcards).
- Answer Writing Evaluation.
- Advanced Heatmaps and Analytics.
- Advanced Full-Text Search (Elasticsearch).
